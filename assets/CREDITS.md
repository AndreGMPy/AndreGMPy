# Asset sources

The 16 Simple Icons technology symbols embedded in tech-stack.svg and tech-stack-mobile.svg are from [Simple Icons](https://github.com/simple-icons/simple-icons/tree/dc7b10662a0a2cfdfc9305e2a2b06c023c30724a/icons), pinned to commit dc7b10662a0a2cfdfc9305e2a2b06c023c30724a. Their path geometry is preserved; a neutral fill is used for this profile's palette.

Simple Icons is distributed under [CC0 1.0 Universal](./SIMPLE-ICONS-LICENSE.md). Brand names and marks identify the technologies only; no affiliation or endorsement is implied.

The hero, project illustrations, section symbols and layouts were created specifically for this profile. All displayed SVG assets are stored in this repository. No CDN, external font, JavaScript, animation, token or statistics service is required.

The VS Code symbol is from [Devicon](https://github.com/devicons/devicon/blob/6a37858047b0e8d9c9c0e68f4a071fc410652e89/icons/vscode/vscode-plain.svg), pinned to commit 6a37858047b0e8d9c9c0e68f4a071fc410652e89. Its geometry is preserved with a neutral fill. The [MIT license](./DEVICON-LICENSE.txt) is included.
